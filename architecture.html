core (server tools) guardrails (denylist, allowlist) module on-disk state optional / not registered

The request path

  • The MCP client posts JSON-RPC over streamable-http to :54321/mcp/.
  • safety.py classifies the command first: HARD rejects cannot be overridden, SOFT ones need dangerous=true.
  • project_allowlist.py resolves the cwd allowlist (global + the nearest .bash-mcp.toml).
  • executor.py spawns bash -lc under the concurrency semaphore, with a timeout and an output cap.
  • Every call is appended to audit.jsonl.

What is stateful

  • sessions.py keeps a cwd + env per session.
  • Since v0.9 that state is mirrored to sessions.db (SQLite) and restored on boot.
  • Opt out with BASH_MCP_SESSION_PERSIST=0.
  • The PreToolUse hook blocks PowerShell shapes that break against WSL (quoting, UTF-16).
  • launcher.sh starts the server in a screen session — this WSL runs systemd=false.
